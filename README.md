Taller 3, Informática 1: Gestión de Datos y MongoDB

Este proyecto es un sistema básico desarrollado en Python para procesar, validar, organizar y almacenar registros biomédicos.

Características Principales:

1. Generación de Datos: Crea 50 registros biomédicos aleatorios (ID, Edad, Frecuencia Cardiaca y SpO2) y los ordena de menor a mayor frecuencia cardiaca.
2. Validación: Verifica que los datos tengan el formato correcto antes de guardarlos.
3. Manejo de Archivos: Guarda automáticamente los registros en carpetas separadas usando los formatos .txt, .csv y .json.
4. Base de Datos NoSQL Se conecta remotamente a MongoDB Atlas para insertar los datos válidos y realizar consultas.
